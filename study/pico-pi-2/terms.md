
| Category               | Term                       | Full name                                   | What it does                                                                                                                                            |
| ---------------------- | -------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CPU                    | **Proc0 / Proc1**          | Processor Core 0 / Processor Core 1         | The RP2040 contains two ARM Cortex-M0+ CPU cores. Your program can use one or both cores to run instructions.                                           |
| CPU                    | **Interrupts**             | Interrupt Controller                        | Temporarily stops normal code so the CPU can immediately handle an event, such as a button press, timer expiration, or incoming UART byte.              |
| CPU                    | **SIO**                    | Single-Cycle Input/Output                   | Provides very fast CPU access to GPIO, inter-core communication, hardware spinlocks, and other low-level functions.                                     |
| Connections            | **GPIO**                   | General-Purpose Input/Output                | Configurable pins used to read digital signals or output digital signals, such as reading a button or controlling an LED.                               |
| Connections            | **GPIO [29:0]**            | GPIO pins 0 through 29                      | The RP2040 supports 30 GPIO signals internally. Not every GPIO is necessarily exposed as a physical Pico pin.                                           |
| Connections            | **IOs**                    | Input/Output subsystem                      | Controls the physical electrical behavior of the chip’s external pins, including voltage levels and pin functions.                                      |
| Debugging              | **SWD**                    | Serial Wire Debug                           | A hardware debugging interface used to program the chip, pause execution, inspect memory, and step through code.                                        |
| Communication          | **UART ×2**                | Universal Asynchronous Receiver/Transmitter | Serial communication commonly used for debug messages or communication with GPS modules, computers, and other microcontrollers.                         |
| Communication          | **I²C ×2**                 | Inter-Integrated Circuit                    | A two-wire bus using SDA and SCL. Commonly connects sensors, OLED displays, RTC modules, and other low-speed devices.                                   |
| Communication          | **SPI ×2**                 | Serial Peripheral Interface                 | A fast synchronous communication bus commonly used for displays, SD cards, ADCs, flash memory, and sensors.                                             |
| Communication          | **USB**                    | Universal Serial Bus                        | Lets the Pico communicate with and receive power from a computer. It can act as a serial device, keyboard, mouse, storage device, and more.             |
| Communication          | **QSPI**                   | Quad Serial Peripheral Interface            | A version of SPI that transfers four bits at once. The Pico primarily uses it to communicate with external flash storage.                               |
| Analog                 | **ADC**                    | Analog-to-Digital Converter                 | Converts an analog voltage into a digital number that your program can read. Useful for potentiometers and analog sensors.                              |
| Analog                 | **TS**                     | Temperature Sensor                          | An internal temperature sensor connected to the ADC. It estimates the chip’s internal temperature.                                                      |
| Signal control         | **PWM**                    | Pulse-Width Modulation                      | Rapidly switches a digital output on and off to simulate variable output levels. Used for LED brightness, motor speed, and servo control.               |
| Timing                 | **Timer**                  | Hardware Timer                              | Measures time, creates delays, schedules alarms, and generates periodic interrupts without manually counting CPU instructions.                          |
| Timing                 | **RTC**                    | Real-Time Clock                             | Tracks date and time while the chip is powered. It is not automatically battery-backed on a normal Pico board.                                          |
| Timing                 | **Watchdog**               | Watchdog Timer                              | Automatically resets the microcontroller when the program freezes or fails to respond within a configured period.                                       |
| Clock                  | **Clock generation**       | Clock Generation System                     | Produces and distributes clock signals that determine how quickly the CPU and peripherals operate.                                                      |
| Clock                  | **Crystal**                | Crystal Oscillator                          | An external component that produces a stable reference frequency for accurate chip timing.                                                              |
| Clock                  | **Internal oscillator**    | Internal Ring Oscillator                    | Generates a clock without requiring an external crystal. It starts quickly but is generally less accurate.                                              |
| Clock                  | **PLL**                    | Phase-Locked Loop                           | Multiplies a lower reference clock into a much faster clock used by the CPU, USB, and peripherals.                                                      |
| Data movement          | **DMA**                    | Direct Memory Access                        | Moves data between memory and peripherals without making the CPU copy every byte. Useful for fast ADC, SPI, UART, PWM, and PIO transfers.               |
| Internal communication | **Bus Fabric**             | Internal Bus Interconnect                   | Connects the CPU cores, memory, DMA controller, and peripherals so they can exchange data.                                                              |
| Programmable hardware  | **PIO**                    | Programmable Input/Output                   | Small programmable hardware engines that handle precise input/output timing independently from the CPU.                                                 |
| Programmable hardware  | **PIO0 / PIO1**            | Programmable I/O Block 0 and 1              | The RP2040 has two PIO blocks. Each block contains multiple state machines that can run small PIO programs.                                             |
| Storage                | **XIP**                    | Execute In Place                            | Allows the CPU to execute program instructions directly from external QSPI flash instead of copying the entire program into SRAM.                       |
| Storage                | **Cache**                  | Instruction Cache                           | Keeps recently accessed flash instructions nearby so the CPU does not repeatedly wait for the slower external flash.                                    |
| Memory                 | **ROM**                    | Read-Only Memory                            | Permanent memory built into the chip containing boot code and useful built-in functions.                                                                |
| Memory                 | **SRAM**                   | Static Random-Access Memory                 | Fast internal working memory used for variables, stacks, buffers, and code that needs to execute quickly. Its contents disappear when power is removed. |
| Memory                 | **Memory banks**           | Separate SRAM Banks                         | SRAM is divided into several banks so different CPU cores, DMA, and peripherals can access memory with less contention.                                 |
| System control         | **Reset control**          | Peripheral Reset Controller                 | Resets individual hardware blocks or holds them in reset until they are ready to be used.                                                               |
| System control         | **Power-on state machine** | Power-On Sequencing Controller              | Controls the chip’s startup sequence and ensures internal hardware powers up in the correct order.                                                      |
| System control         | **Sysctrl**                | System Control                              | Provides low-level control over system behavior, clocks, power, and other chip-wide functions.                                                          |
| System control         | **Sysinfo**                | System Information                          | Provides information about the chip, such as identification and hardware configuration.                                                                 |
| Power                  | **Core Supply Regulator**  | Internal Core Voltage Regulator             | Converts the external supply voltage into the lower voltage required by the CPU and other internal logic.                                               |
| General                | **Peripherals**            | Hardware Peripheral Blocks                  | Dedicated hardware components such as UART, SPI, I²C, PWM, timers, and ADC that perform tasks without implementing everything in software.              |
